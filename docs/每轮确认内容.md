## 第二轮：确认清单批注与冲突裁定（9月18日阶段）

### 即时结局与外派

### 招聘与计数

- 每3次成功奖励必须当场选，未满3次进度跨月保留。

- 每连续两次失败扣1信任，成功清零，四连败扣2；跨月保留连续计数。
- 特殊事件必成功也占用一次保底周期；重合只产生一个成功。

### 成长与月份

- 每点属性+1；运动就是选健康。
- 连续4个月未选健康开始每月多巴胺-1，选健康清零计数。
- 每章健康和英语均选过，多巴胺+1。
- 全部增减后连续7个月多巴胺<3结束；恢复到3清零。
- 2019年12月无技能点，不增加未选健康计数；已有状态仍做月度扣减、低值及章末检查。全程41点。

### 经济与竞猜

- 金额到分，利息和返还 HALF_UP。月底先本月工资，再涨薪及年末新工资奖金，再还款，再计息破产，再加点。
- 每场一次，提交不可改，先结旧再开新；第 n 次有效下注上限5000×1.3^(n-1)，按存档实际有效提交累计。最低500，取消原额退款且撤销计数，金额按分 HALF_UP。
- 本轮暂保留首年18%、最低3000及零运气猜中净0。注意：这三项已在第四轮明确替代，不得继续实现。

## 第十一轮：全面 UI 交互改版（2026-10-11）

作者在真机试玩后提出整屏改版要求，逐条落地如下。

### 系统提示文字

- 系统提示不再是普通正文段落，统一放进**专用提示框**，字体、字号、字距与正文明确区分（提示标题用 13sp/字距 1.6sp、正文用 15sp/Medium 字重），并有**独立的入场动画**（200ms），与页面其它文字不同步。
- 作者要求“提供几种方案”。已实现三套并出图：**A 标签条**（左侧天蓝竖条 + 宽字距标签，从左侧滑入）、**B 气泡卡片**（圆形图标底 + 卡片，弹簧弹出）、**C 终端条**（深色条 + 等宽字体，顶部天蓝细线从左擦出）。作者已选定**混用**：警告用 A、普通提示用 B，两套共用同一组度量（同宽、同内边距、同字号），只有强调件不同（A 是左侧强调条，B 是圆形图标底）。C 保留在代码里但未挂到界面。
- 提示文案改短：如“今天的两份简历已经送到。看仔细一点。”保留原句但提示标题只写“今日”。

### 排版与结构

- **新闻改为屏幕中央的弹窗**：圆角卡片、缩放弹出，带“收起/展开”按钮，收起后只剩标题条（即“变回原样”），另有“关闭”。
- **所有内容面板垂直居中**，不再从顶部往下堆：工作日入口、经济面板、能力面板、奖励、技能、结局都居中；内容高于屏幕时仍可滚动。
- **顶栏改成两行**：第一行是“状态 / 档案袋 …… 日历”，第二行居中放大日期 + 月份胶囊。这修掉了英文界面下 “Calendar” 被挤成竖排字母塔的问题。
- **能力/状态面板改成小组件式网格**：钱务与统计用横排小卡（现金|负债，月薪|累计录用|审阅正确），六个属性用竖排能量格，版式有横有竖。
- **经济面板加钱的纹路背景**（金币圆环 + ¥ 纹，6–9% 透明度），与下方的能力面板区分。

### 字体与配色

- 全文**加粗一档**（正文 Normal→Medium，标题 SemiBold→Bold），圆角整体放大（卡片 20→24dp）。
- **简历界面改用衬线字体**（`FontFamily.Serif`，中英均可用系统衬线），履历读起来像纸质档案；剧情正文也用衬线。

### 交互与动效

- **按钮分级**：天蓝底白字（主操作）、卡其容器（次要）、淡天蓝底深蓝字（就地操作）、细描边（返回）。

### 定稿内容

| 用途 | 家族 | 授权 | 说明 |
| --- | --- | --- | --- |
| UI 无衬线（拉丁） | Nunito 400/600/700 | SIL OFL 1.1 | 圆头圆角，界面友好感 |

| 等宽 | JetBrains Mono 400/500 | SIL OFL 1.1 | 简历编号、终端条提示 |

- 组织方式为「拉丁在前、中日韩在后」的家族，依赖 Android 字形回退：英文走 Nunito / Space Grotesk / Source Serif，中文走思源黑体 / 思源宋体。
- 中日韩字形按游戏实际用字（2051 汉字，含内容包与界面文案）子集化，整包 **4.9MB**；APK 16.5 → 18.6MB。
- 装配位置 `app/src/main/java/com/example/hrrepayment/ui/theme/Type.kt` 的 `AppFonts`；素材与授权原文在 `assets/fonts/`；生成脚本 `tools/build_fonts.py`。

### 覆盖保证（实测，不是声称）

新增设备测试 `FontCoverageInstrumentedTest`，用 `Paint.hasGlyph` 逐个字符问字体“有没有这个字”，字符集取自内容包（252 工作日全部简历、陈述、核对资料、新闻、竞猜）与 `Key` 枚举里的全部中英界面文案：

- Noto Sans SC 三种字重：**0 缺字**（断言为严格相等）；
- Noto Serif SC 两种字重：缺字 ≤ 12（分片边界，断言为上限）；
- 九个拉丁字重：A–Z / a–z / 0–9 **0 缺字**。

### 已知边界

- **API 24–25 不做家族内字形回退**：只取家族里的第一个字体，中文会落到系统字体（可读，但中英风格不完全统一）；API 26+ 正常。
- Noto Serif SC 子集有极少数缺字（分片边界），会回退系统字体；要 100% 覆盖用完整版思源宋体重新子集化即可。
- 字体为 OFL，可商用可嵌入 APK，再分发时保留 `assets/fonts/licenses/`。


## 第十三轮：结局字体与结局 UI 重做（2026-10-11）

作者：“我感受不到字体的设计感，尝试给结局的文字修改字体，采取更史诗感的版本，并且尝试修改结局UI”；随后明确“**不要书法体，参考梅赛德斯奔驰的中文字样**”。

### 字体方向（已按作者意见收窄）

- 豪华品牌中文标识的做法是**细笔画、极大字距、零装饰**，靠比例与留白而非书法感。据此结局标题改用**思源宋体 ExtraLight/Light（200/300）+ Cormorant Garamond**，标题字距 5sp、小标签字距 5sp、正文行高 1.76。
- 已下载的书法体（Ma Shan Zheng）按作者要求**弃用**，不进入工程。
- 结局标题按字数自适应字号与字距，保证永远单行；配色仍按结局性质分档（绿/天蓝/卡其/红）。

### 第十轮补充（作者复审后修正，2026-10-11）

作者在预览图上指出两处不符合要求，均确认为实现缺陷，已修正：

- **用户须知面板此前打不开。** 我按设计稿做成了“未勾选时点《用户须知》只抖动、不打开”，实际等于玩家读不到条款才被迫同意。现改为**任何时候点《用户须知》都打开面板**，读完点“我已知晓”即同时完成勾选；抖动规则取消。
- **未勾选仍能进入游戏。** 上一版只拦了存档槽按钮，“新建游戏 / 读取游戏”本身没拦。现改为**未勾选时这两个按钮直接禁用（灰显）**，并在按钮下方用红字写明“请先勾选《用户须知》”；存档槽按钮同样禁用。**“切换语言”保持可用**，否则非中文玩家无法先把界面切成英文再读条款——如作者要求连它一起锁，改一行即可。
- 《用户须知》入口改为带图标、蓝色下划线的链接样式，明确可点；开场面板“我已了解并接受以上内容”整行都可点，不再只有 18dp 的复选框能点。

另外自查出并修掉一个实现缺陷：**面试档案袋会自动弹出**。原因是“关闭”与“打开但为空”都用空列表表示，于是每次存档写入和每次切换语言后，档案袋覆盖层都会自己弹出来。现改为 `null` 才表示关闭，只有玩家点入口才打开；已补单元回归测试与设备断言。
